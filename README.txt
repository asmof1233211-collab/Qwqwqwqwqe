دِراستي — نسخة أولية للآيفون

المحتويات:
- index.html: التطبيق.
- manifest.webmanifest و sw.js: دعم التثبيت والعمل الأساسي دون اتصال بعد أول زيارة.
- الأيقونات: أيقونة الشاشة الرئيسية.

طريقة التثبيت على iPhone:
1) ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify).
2) افتح رابط الموقع في Safari على iPhone.
3) اضغط زر المشاركة ثم "إضافة إلى الشاشة الرئيسية" ثم "إضافة".

مهم:
- المهام والجدول والملخصات النصية تحفظ محلياً في متصفح الجهاز.
- المساعد الذكي يفتح ChatGPT عبر الإنترنت بطلب جاهز؛ لا يوجد اتصال API مباشر في هذه النسخة.
- الاختبارات تولّد طلباً لبدء تدريب في ChatGPT وليست أرشيفاً رسمياً للأسئلة الوزارية.
- رفع الملفات وحفظها بشكل دائم داخل التطبيق يحتاج مرحلة تطوير إضافية.
- لا تضع مفاتيح API سرية داخل ملفات الواجهة.
